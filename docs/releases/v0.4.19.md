# DashDesign 0.4.19

- 图片修改新增多模态 Agent：结合原图理解自然语言要求，整理为图像模型提示词后自动执行编辑。
- 遇到对象不明确、要求冲突或缺少必要文字时先询问，补充回答后继续同一任务。
- 可展开查看中文修改摘要与最终提示词，原始要求保持不变。
- 新增独立的图片编辑 Agent 模型配置；未指定时沿用有效文本模型，需支持图文输入和 JSON 输出。
- 转写失败即停止，不将原始要求直接发送到图片模型；支持手动重试转写。
- 保存原图快照、澄清历史和转写结果，防止过期回答和同一任务重复出图。

部署顺序：先升级云端 API，再升级客户端。旧客户端省略新增配置字段时不会覆盖已有值。

验证范围：本地 503 项测试通过；真实上游 `gpt-5.5` → `gpt-image-2` 已完成“澄清 → 回答 → 图片编辑”联调。上游实际返回尺寸可能偏离请求；复杂海报文字、打印尺寸和无损保真仍需成品验收。安装包构建不等同于 Windows 实机安装或 macOS 公证验证。
